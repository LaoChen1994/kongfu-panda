# 《竹林守卫：熊猫乱斗》游戏设计文档

> 文档版本：v1.0
> 状态：立项设计基线  
> 更新日期：2026-09-03
> 适用范围：玩法、美术、程序、数值、音频、测试与后续内容设计

## 0. 文档使用规则

本文档是本项目当前唯一的游戏设计基线。后续设计与开发必须遵循以下规则：

1. 开始设计、编码或制作资源前先阅读本文档相关章节。
2. 文档明确写为“固定”的内容，未经确认不得改变。
3. 标记为“测试基线”的数值允许通过试玩调整，但调整后必须同步回写本文档。
4. 新角色、新系统、新货币、新装备槽和新玩法不自动进入范围，必须先说明价值、成本和影响。
5. 用户的新明确要求优先于本文档；两者冲突时先指出冲突，再确认是否修改设计基线。
6. 所有已确认的设计变更必须记录在文末“版本记录”中。

## 1. 产品概述

### 1.1 暂定名称

《竹林守卫：熊猫乱斗》

### 1.2 核心定位

一款以原创熊猫武者为主角的俯视角 2D 割草肉鸽游戏。玩家在限定波次内移动、闪避和自动攻击，通过局内升级、武器组合、道具构筑和波次商城形成流派，每 5 波迎战一次 Boss，最终守住被妖气侵蚀的竹林。

### 1.3 核心体验

- 大量敌人被快速击败的割草爽感。
- 每局都能形成不同构筑的肉鸽变化。
- 熊猫职业之间有明显而易懂的打法差异。
- 商城决策会直接影响下一波战斗。
- 操作门槛低，但走位、闪避和构筑选择有成长空间。
- 单局时间可控，失败后愿意立刻重开。

### 1.4 参考边界

可以参考同类波次制割草游戏的节奏、构筑密度和商店体验，但角色、命名、世界观、视觉、技能、道具和数值必须保持原创，不直接复刻具体作品内容。

## 2. 固定设计决策

以下内容在 v0.1 阶段固定：

| 项目 | 决策 |
|---|---|
| 游戏类型 | 俯视角 2D、割草、肉鸽、波次制 |
| 首发平台 | 桌面浏览器 |
| 引擎 | Phaser + TypeScript + Vite |
| 操作 | WASD/方向键移动，自动攻击，Space 闪避 |
| 单局结构 | 正式版 15 波，MVP 10 波 |
| Boss 节点 | 正式版第 5、10、15 波；MVP 第 10 波最终 Boss |
| 商城 | 每个普通波次结束后进入 |
| 初始角色 | 3 只熊猫 |
| 后续角色 | 再解锁 3 只，共 6 只 |
| 战斗界面 | Canvas/WebGL 战场 + DOM HUD/菜单 |
| 局外成长 | 以内容解锁为主，不做重度永久数值碾压 |
| MVP 联机 | 不做 |
| MVP 移动端 | 不做，仅保证页面不会完全不可用 |

## 3. 设计支柱

### 3.1 熊猫职业必须一眼可辨

不同熊猫不能只靠基础数值区分。每个角色必须同时具备：

- 独特轮廓与配色。
- 明确的优势与弱点。
- 改变构筑方向的被动。
- 一件不可出售的专属武器。

### 3.2 每次选择都能影响构筑

升级、购买和 Boss 奖励应围绕流派标签产生联系。玩家在第 5 分钟左右应该能够描述自己的构筑，例如“高攻速飞镖流”“护盾反伤流”或“范围棍法吸血流”。

### 3.3 战场优先于界面

正常战斗时，画面中心和下方移动区域不得被大型 UI 遮挡。升级、商城和结算界面出现时暂停战斗。

### 3.4 反馈清晰优先于特效数量

玩家必须能够看清：

- 自己为什么受伤。
- Boss 下一次攻击会落在哪里。
- 哪些掉落物是经验、铜钱或治疗。
- 当前构筑的核心触发效果。

## 4. 世界观与主题

### 4.1 世界背景

灵竹谷依靠“月心竹”维持四季与灵气。腐化妖雾侵入竹林后，动物被妖气控制，竹根也开始异变。六位来自不同流派的熊猫守卫进入谷中，清除妖兽并修复月心竹。

### 4.2 叙事方式

MVP 不制作长剧情和大量对白。叙事通过以下内容表达：

- 角色选择页的一句话背景。
- Boss 出场演出。
- 地图从清新竹林逐渐腐化的环境变化。
- 道具名称和简短描述。
- 通关后的单屏结算文案。

### 4.3 语气

整体轻松、热闹、带少量武侠夸张感。避免沉重写实和恐怖血腥表现。击败敌人以烟雾、竹叶、星光和妖气消散代替血液。

## 5. 美术风格方案

### 5.1 风格方向

采用“东方绘本 + 卡通武侠”的 2D 风格：

- 轮廓圆润，角色头身比约 1:1.5 至 1:2。
- 形状语言明确，远距离仍能识别职业。
- 色块清楚，避免角色毛发和服装出现过多碎细节。
- 动作夸张、重心清楚，强调熊猫的重量感和弹性。
- 场景具有水墨晕染感，但战斗碰撞区域保持清晰。

### 5.2 视觉关键词

`圆润`、`武侠`、`竹林`、`绘本`、`清晰轮廓`、`夸张动作`、`温暖幽默`、`妖气反差`

### 5.3 主色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 竹林主绿 | `#4F8F55` | 场景主体 |
| 嫩竹亮绿 | `#9BCB66` | 经验、成长和正向反馈 |
| 宣纸米白 | `#F3E6C8` | 菜单、卡片和文字底色 |
| 墨色 | `#202622` | 轮廓、标题和熊猫深色部分 |
| 铜钱金 | `#E3A83B` | 商城和货币 |
| 妖气紫 | `#7651A8` | 腐化、敌人和负面状态 |
| 危险红 | `#D9554D` | 伤害、警告和 Boss 预警 |
| 气功青 | `#53B8B2` | 气功、护盾和特殊能量 |

### 5.4 角色视觉规则

- 熊猫脸部黑白关系保持一致，职业通过服装、武器和点缀色区分。
- 近战使用宽肩、粗腰带和大面积暖色。
- 远程使用轻装、长飘带和青绿色。
- 肉盾使用方形护具、石纹和深灰色。
- 狂战士使用红褐色、绷带和酒葫芦元素。
- 机关师使用工具包、木质机关和铜色零件。
- 气功师使用长袍、念珠和青蓝色能量。
- 任何职业都不能依靠 HUD 名称才能被辨认。

### 5.5 敌人视觉规则

- 普通追击敌人：圆形或三角形轻量轮廓。
- 冲锋敌人：前重后轻，突出角、肩甲或蓄力方向。
- 远程敌人：高挑轮廓，武器与弹道颜色一致。
- 坦克敌人：方形大体积，护甲面朝向明确。
- 增益和召唤敌人：具有高亮饰物，确保玩家能优先识别。
- 精英敌人增加金色或紫色外圈，但不只靠换色表达。

### 5.6 场景规则

- 战斗地面使用低对比纹理，不能与经验和铜钱争夺注意力。
- 可碰撞障碍必须有明确轮廓；MVP 场景不设置复杂迷宫障碍。
- 地图边缘通过竹林、石墙和雾气自然封闭。
- 每 5 波改变一次环境光、妖气浓度和背景细节，强化阶段感。

### 5.7 特效规则

- 玩家攻击：明亮、短促、偏金绿或角色职业色。
- 敌人攻击：紫红色，并提前显示危险预警。
- 暴击：尺寸更大的伤害数字、短促闪光和更重音效。
- 护盾：贴身墨青气罩与局部高光，获得或受击时短暂增强，破裂时有明显碎片动画；不得用常驻完整圆环遮挡角色。
- 治疗：绿色向上粒子，不与经验掉落混淆。
- 同屏特效过多时优先降低粒子数量，不降低危险预警可见度。
- Boss 根刺预警使用腐化土地、地下根须与不闭合危险边缘表达实际范围，不使用完整红色圆圈或调试感叉线。
- 铁竹盾击只在攻击方向显示短促盾面、震线和碎石，护盾本体不得与攻击范围混成同尺寸圆环。

### 5.8 角色动画规格

MVP 每只熊猫至少包含：

| 动画 | 建议帧数 | 说明 |
|---|---:|---|
| Idle | 6 | 轻微呼吸和重心变化 |
| Run | 8 | 四方向可先用水平翻转与近似角度 |
| Attack | 6–8 | 专属武器攻击 |
| Roll | 6 | 明确起始、无敌区间和结束 |
| Hurt | 3 | 短促，不长时间打断控制 |
| Death | 8 | 倒地或化为竹叶烟雾 |

资源制作采用同一批准种子帧生成整条动画，再统一底部中心锚点和缩放。不得逐帧独立生成导致角色漂移。

MVP 普通敌人至少包含移动与攻击两组动画；追击敌人表现扑咬，冲锋敌人表现蓄力与突进，远程敌人表现聚气与发射。角色和敌人根据水平移动方向翻转，垂直移动允许使用俯视 3/4 近似角度，不要求为 M0 单独制作四套方向帧。

### 5.9 UI 视觉语言

- 材质使用宣纸、竹木边框、墨迹和铜扣。
- 卡片边角圆润，但避免现代 SaaS 面板风格。
- 稀有度通过边框、图标和轻度发光共同表达，不能只靠颜色。
- 正文字体优先高可读中文字体；标题可以使用带书法感但不影响识别的字体。
- 强动画只用于升级、Boss、购买成功、稀有掉落和通关。
- 桌面浏览器所有可读文字最小字号为 14px；标题、关键数值和商城价格必须在此基础上建立更明显层级。

## 6. 核心玩法设计

### 6.1 玩家主要行为

- 移动并保持安全距离。
- 利用闪避穿过危险区域。
- 收集经验、铜钱和治疗物。
- 在升级时选择属性或天赋。
- 在商城中购买、合成、锁定和出售。
- 根据 Boss 和敌人组合调整构筑。

### 6.2 单局循环

```text
选择熊猫
→ 进入波次
→ 击杀与拾取
→ 局内升级三选一
→ 波次结束
→ 商城补给与构筑调整
→ Boss 检验
→ 通关或失败结算
→ 解锁新内容
```

### 6.3 正式版波次结构

| 波次 | 时长基线 | 内容 |
|---|---:|---|
| 1–2 | 50 秒 | 基础追击敌人，建立操作认知 |
| 3–4 | 55 秒 | 加入快速和远程敌人 |
| 5 | 75 秒 | Boss：獠牙先锋 |
| 6–7 | 60 秒 | 增加敌群密度和坦克敌人 |
| 8–9 | 65 秒 | 加入增益和召唤敌人 |
| 10 | 90 秒 | Boss：赤羽妖鹤 |
| 11–12 | 65 秒 | 精英敌人稳定出现 |
| 13–14 | 70 秒 | 高密度混合敌潮 |
| 15 | 100 秒 | 最终 Boss：腐竹巨灵 |

完整单局目标时长为 18–22 分钟，包含升级和商城决策时间。

### 6.4 胜负条件

- 玩家生命降至 0：本局失败。
- 击败第 15 波最终 Boss：本局胜利。
- Boss 波超时：敌人进入狂暴，伤害和移动速度持续增加，不立即判负。
- 暂停和打开升级/商城时停止战斗计时。

## 7. 操作、移动与镜头

### 7.1 输入映射

| 动作 | 键位 |
|---|---|
| 移动 | WASD / 方向键 |
| 闪避 | Space |
| 确认 | Enter / 鼠标左键 |
| 取消或暂停 | Esc |
| 查看角色信息 | Tab |

### 7.2 移动规则

- 使用八方向连续移动。
- 对角线移动速度必须归一化。
- 玩家与普通敌人产生软碰撞和推挤，不因重叠完全卡死。
- 地图边界为硬边界。
- MVP 不加入冲刺攻击、跳跃和复杂体力系统。

### 7.3 闪避规则

- 测试基线冷却：3 秒。
- 测试基线持续：0.35 秒。
- 中段提供短暂无敌时间，起步与收尾仍可受伤。
- 闪避方向由当前移动方向决定；无输入时沿最后移动方向。
- 闪避不能穿越地图边界和永久障碍。

### 7.4 镜头

- 固定俯视角，镜头平滑跟随玩家。
- 普通攻击不产生大幅镜头震动。
- Boss 落地、护盾破裂和重型暴击可使用短促轻震。
- 提供关闭镜头震动选项。

## 8. 战斗系统

### 8.1 攻击方式

- 武器自动寻找有效目标并攻击。
- 默认目标为攻击范围内距离最近的敌人。
- 不同武器可以覆盖“最近目标”“生命最高目标”“随机目标”或“角色朝向”。
- 玩家主要负责走位、闪避和构筑，不在 MVP 中加入多个主动技能键。

### 8.2 伤害类型

MVP 只保留三种逻辑标签，不制作复杂元素克制：

- 直接伤害：普通近战和投射物。
- 持续伤害：燃烧、毒雾和地面区域。
- 召唤伤害：炮塔、陷阱和召唤物。

### 8.3 命中反馈

- 普通命中：受击闪白、轻粒子、短音效。
- 暴击：更大数字、金色闪光、重音效。
- 击杀：敌人轮廓压缩并化为妖气与掉落物。
- 玩家受伤：屏幕边缘短暂红色提示，角色闪烁但不遮挡战场。
- 同一帧大量伤害数字应聚合或限制数量，避免覆盖敌人预警。
- 近战横扫的特效边界必须与实际命中范围一致，并沿自动选定的最近目标方向展开；普通命中产生轻击退，暴击产生更强击退。
- 玩家近战、飞叶弹道与击杀反馈统一使用竹绿/铜金；敌方投射物统一使用妖紫核心与危险红拖尾，不能只依赖来源位置区分敌我。
- 飞叶必须显示飞行方向、旋转和双层拖尾，命中效果沿飞行方向展开；普通命中停顿不超过 20ms，暴击停顿不超过 45ms。

### 8.4 基础伤害公式

测试基线：

```text
最终伤害 = 武器基础伤害 × (1 + 伤害加成) × 暴击倍率 × 其他独立倍率
减伤率 = 护甲 / (护甲 + 60)
实际承伤 = 原始伤害 × (1 - 减伤率)
```

属性上限基线：

| 属性 | 上限或下限 |
|---|---:|
| 闪避 | 45% |
| 暴击率 | 75% |
| 攻击速度 | 200% 基础值 |
| 冷却 | 最低为基础冷却的 45% |
| 移动速度 | 150% 基础值 |
| 护甲减伤 | 75% |

上限用于防止单一属性让玩法失效，最终数值以试玩为准。

## 9. 熊猫角色设计

### 9.1 统一角色模板

每只熊猫的数据必须包含：

- 基础生命、移动、护甲、伤害和攻速修正。
- 一项清晰优势。
- 一项真实弱点。
- 一个角色被动。
- 一件专属武器。
- 推荐构筑标签，但不锁死其他玩法。

### 9.2 初始开放角色

#### 山岚——近战武者

- 定位：近战范围输出、轻度续航。
- 生命：20。
- 近战伤害：+15%。
- 攻击范围：-10%。
- 被动“连山棍势”：每第 4 次近战攻击触发一次 180 度旋风斩，并恢复 1% 最大生命；单次触发最多命中 8 个敌人。
- 专属武器：竹节棍。
- 推荐标签：近战、范围、吸血、攻速。
- 弱点：前期需要靠近敌群，远程处理能力差。

#### 青团——飞叶射手

- 定位：远程持续输出、灵活走位。
- 生命：10。
- 移动速度：+10%。
- 投射物速度：+20%。
- 近战伤害：-20%。
- 被动“散叶”：每第 6 发投射物分裂为三枚伤害为原攻击 45% 的小竹叶。
- 专属武器：竹叶飞镖。
- 推荐标签：远程、投射物、暴击、穿透。
- 弱点：容错低，受到包围时难以脱身。

#### 石墨——镇岳守卫

- 定位：护甲、护盾、反击。
- 生命：30。
- 护甲：+8。
- 移动速度：-10%。
- 被动“山岳护体”：每 8 秒获得相当于 8% 最大生命的护盾；护盾被击破时造成一次范围震击。
- 专属武器：铁竹盾。
- 推荐标签：护盾、反伤、范围、生命。
- 弱点：移动和清怪速度较低，需要用反击弥补输出。

### 9.3 后续解锁角色

#### 赤豆——醉拳狂战士

- 定位：低生命高攻速。
- 被动：每损失 10% 生命获得 6% 攻击速度，最多叠加 5 层。
- 专属武器：酒葫芦拳套。
- 弱点：高收益区间同时也是高死亡风险区间。

#### 墨墨——竹机关师

- 定位：炮塔、陷阱和召唤物。
- 被动：召唤伤害 +25%，直接伤害 -15%；每击杀一定数量敌人部署一个临时竹弩。
- 专属武器：便携竹弩台。
- 弱点：需要时间建立输出区域，频繁移动时效率下降。

#### 白露——太极气宗

- 定位：环绕物、控制和范围爆发。
- 被动：拾取经验时积累气值，满气后自动释放一次牵引冲击波。
- 专属武器：太极气珠。
- 弱点：对单体 Boss 的持续伤害较弱。

后三只角色不进入 MVP，具体数值在进入制作前单独评审。

## 10. 局内属性与升级设计

### 10.1 属性池

- 最大生命
- 伤害
- 攻击速度
- 暴击率
- 暴击伤害
- 护甲
- 闪避
- 移动速度
- 生命恢复
- 拾取范围
- 幸运
- 冷却缩减
- 攻击范围
- 投射物数量
- 穿透
- 击退

### 10.2 升级流程

- 击杀敌人掉落灵竹经验。
- 经验达到阈值后暂停战斗。
- 玩家从三个候选项中选择一个。
- 每波第一次升级刷新免费，之后刷新消耗少量铜钱。
- 候选池根据角色、武器和道具标签动态加权。
- “竹息养生”每次使最大生命 +5，并立即恢复 5 点生命；低初始生命使生存升级成为明确构筑选择。

### 10.3 候选保护规则

每次三选一必须满足：

- 至少一个选项对当前构筑有效。
- 不同时出现三个纯防御或三个纯移动选项。
- 已达上限的属性不再出现。
- 与当前角色完全冲突的强化降低权重，但不全部禁止实验构筑。
- 连续两次未出现构筑主标签时，下一次提高该标签权重。

### 10.4 升级稀有度

| 稀有度 | 基础概率 | 效果定位 |
|---|---:|---|
| 普通 | 60% | 小幅单属性提升 |
| 稀有 | 27% | 中幅提升或双属性组合 |
| 史诗 | 10% | 强力流派效果，常带代价 |
| 传说 | 3% | 改变构筑方式，不只增加数字 |

幸运属性可以移动概率，但不能让传说成为常态。

### 10.5 天赋示例

| 名称 | 稀有度 | 效果 |
|---|---|---|
| 横扫千军 | 稀有 | 近战范围 +15%，攻击速度 -5% |
| 竹叶连射 | 稀有 | 远程攻击有 12% 概率追加一枚 50% 伤害投射物 |
| 荆棘皮毛 | 稀有 | 受到接触伤害时反弹固定伤害 |
| 熊猫滚滚 | 史诗 | 闪避结束造成范围伤害，闪避冷却 +0.4 秒 |
| 越战越勇 | 史诗 | 本波每击杀 50 个敌人，伤害 +2%，波次结束清空 |
| 食铁体质 | 史诗 | 拾取治疗时获得短暂护甲，基础治疗效果 -10% |
| 万竹归心 | 传说 | 每拥有一种竹类武器，提高全部武器伤害，但商城非竹类武器减少 |

## 11. 武器设计

### 11.1 装备槽

- 1 个专属武器槽：角色自带，不可出售。
- 3 个通用武器槽。
- 6 个宝物槽。
- 消耗品购买后立即使用，不占槽位。

MVP 不增加副手、护甲、戒指等额外装备栏。

### 11.2 武器等级

- 武器等级为 1–5。
- 商城买到同名同级武器时可以合成升级。
- 升级主要提升基础伤害、攻速、范围或投射物效果。
- 5 级武器搭配指定宝物后可以进化。
- 进化是玩法变化，不只是数值翻倍。

### 11.3 MVP 武器目录

| 武器 | 标签 | 核心行为 | 适合构筑 |
|---|---|---|---|
| 竹节棍 | 近战、范围 | 前方扇形横扫 | 山岚、范围、吸血 |
| 铁锅拳套 | 近战、攻速 | 短距离快速连击 | 暴击、攻速 |
| 竹叶飞镖 | 远程、投射物 | 向目标发射飞镖 | 青团、穿透、暴击 |
| 爆竹筒 | 远程、爆炸 | 慢速发射范围爆炸物 | 范围、冷却 |
| 旋转竹刃 | 气功、环绕 | 围绕角色持续旋转 | 贴身、防御、触发 |
| 铁竹盾 | 防御、反击 | 周期性向前盾击 | 石墨、护甲、击退 |
| 熊猫酒葫芦 | 持续、区域 | 喷出短时燃烧区域 | 持续伤害、范围 |
| 竹弩机关 | 机关、召唤 | 放置临时自动炮塔 | 召唤、站位 |

### 11.4 MVP 进化路线

| 原武器 | 条件宝物 | 进化武器 | 变化 |
|---|---|---|---|
| 竹节棍 Lv5 | 武道腰带 | 盘龙金竹 | 横扫变为环形连击，末击击退 |
| 竹叶飞镖 Lv5 | 风羽 | 万叶归宗 | 飞镖穿透并在末端分裂回射 |
| 铁竹盾 Lv5 | 镇岳石 | 不动熊山 | 护盾破裂时生成持续震地波 |

### 11.5 武器攻击与成长表现规范

每件武器必须同时具备独立的攻击几何、有效范围、节奏、弹道或轨迹、命中特效和成长节点表现。武器升级不能只提高伤害数字；至少一个等级节点需要明显改变范围、数量、持续时间、穿透、连击或部署数量，并保持视觉边界与实际判定一致。

| 武器 | 攻击几何与范围特征 | 基础特效语言 | 成长获得感 |
|---|---|---|---|
| 竹节棍 | 面向目标的中距离宽扇形横扫 | 嫩竹气流、铜金外弧、短叶痕 | 扇形与半径扩大，第 4 击变为 180° 旋风 |
| 铁锅拳套 | 极短距离窄扇形连续拳击 | 铜色拳风、双段冲击点 | 连击次数和攻速提高，末击冲击更重 |
| 竹叶飞镖 | 长距离定向投射物 | 飞叶主体、墨色外拖尾、嫩竹内芯 | 数量、分裂、穿透和末端回射逐步可见 |
| 爆竹筒 | 慢速直线弹道与落点圆形爆炸 | 暖金火星、朱红爆圈、短烟团 | 爆炸半径、连锁次数或多弹齐射增加 |
| 旋转竹刃 | 贴身环绕轨道 | 竹青旋光、铜金刃口、环形风线 | 环绕数量、轨道半径或旋转速度增加 |
| 铁竹盾 | 面向目标的短距离窄扇形盾击 | 气功青盾面、厚重震线、碎石点 | 击退、盾宽和破盾震地范围增加 |
| 熊猫酒葫芦 | 面向目标的短锥形喷洒与地面区域 | 琥珀液滴、暖红火舌、低透明热浪 | 区域面积、持续时间和同时存在数量增加 |
| 竹弩机关 | 固定位置部署并向最近目标射击 | 木铜机关闪光、细直弩线、落地阵纹 | 炮塔数量、射速或齐射数量增加 |

玩家武器使用竹绿、铜金、气功青和暖红等职业色；敌方弹幕固定使用妖紫核心与危险红拖尾。高密度场景中优先保留敌方弹道轮廓和危险预警，再减少玩家装饰粒子。

## 12. 道具设计

### 12.1 道具原则

- 道具应强化流派或制造取舍，不应全部是无脑增益。
- 同一强力效果最多允许有限叠加。
- 传说道具必须改变行为或规则。
- 道具描述必须明确数值、触发条件、持续时间和上限。
- 道具效果不得依赖玩家无法观察的隐藏条件。

### 12.2 MVP 道具目录

#### 生存类

| 道具 | 稀有度 | 效果基线 |
|---|---|---|
| 竹露丸 | 普通 | 最大生命 +10 |
| 铁砂护腕 | 普通 | 护甲 +4，移动速度 -3% |
| 食神饭盒 | 稀有 | 每波开始恢复 15% 最大生命 |
| 倒刺背甲 | 稀有 | 获得反伤，闪避 -5% |
| 镇岳石 | 史诗 | 护盾效果 +25%，移动速度 -5% |
| 不倒翁护符 | 史诗 | 受到致命伤害时保留 1 点生命，每局一次 |

#### 直接输出类

| 道具 | 稀有度 | 效果基线 |
|---|---|---|
| 武道腰带 | 普通 | 近战伤害 +10% |
| 翡翠眼罩 | 稀有 | 暴击率 +8%，最大生命 -5 |
| 风羽 | 稀有 | 投射物速度 +20%，远程伤害 +5% |
| 双生竹节 | 史诗 | 投射物 +1，单发伤害 -15% |
| 猛虎印 | 史诗 | 对精英和 Boss 伤害 +18%，对普通敌人伤害 -5% |
| 破军令 | 传说 | 暴击击杀会造成小范围爆炸，暴击伤害 -20% |

#### 攻速与冷却类

| 道具 | 稀有度 | 效果基线 |
|---|---|---|
| 疾风绑腿 | 普通 | 攻击速度 +8% |
| 武僧念珠 | 稀有 | 冷却缩减 +10%，普通攻击伤害 -5% |
| 连环铜扣 | 稀有 | 连续命中同一目标时逐步增加伤害，换目标后重置 |
| 雷纹手鼓 | 史诗 | 每第 10 次攻击释放闪电链，攻击速度 -5% |

#### 经济与成长类

| 道具 | 稀有度 | 效果基线 |
|---|---|---|

| 商会令牌 | 史诗 | 每次刷新至少出现一件稀有物品，刷新费用 +3 |

|---|---|---|

| 竹林图腾 | 史诗 | 停留 2 秒后获得持续增伤，移动后逐渐消失 |

### 12.3 叠加和互斥规则

- 普通数值道具可以重复购买。
- 带“每局一次”效果的道具不可重复出现。
- 改变同一武器最终进化的宝物互斥。
- 额外投射物、闪避无敌和复活类效果需要单独设置叠加上限。
- 商城必须在购买前提示该道具是否会触发上限或冲突。

### 12.4 构筑系统一期接入范围

- 商城首批接入 12 件可购买宝物：武道腰带、风羽、铁砂护腕、熊猫滚轮、竹露丸、食神饭盒、翡翠眼罩、疾风绑腿、镇岳石、招财熊爪、聚灵竹筒和猛虎印。
- 普通、稀有、史诗商品按 60% / 27% / 13% 的商店稀有度权重抽取；同屏仍保持商品 ID 互不重复。
- 角色、已装备武器和生存类宝物共同影响升级候选保护，三选一至少保留一个与当前近战、远程或生存构筑相关的选项。
- 食神饭盒的 15% 最大生命恢复与基础波次恢复相加；招财熊爪使用小数累计保证 12% 铜钱增益在小额掉落上长期生效。
- 行囊按宝物 ID 合并显示数量、实际效果和单件出售价格，同时显示宝物总件数；完整属性面板仅在战斗暂停的商城中展开。

## 13. 商城与经济设计

### 13.1 货币

- 灵竹经验：只用于局内升级，波次结束不兑换。
- 铜钱：用于商城消费。
- 竹印：局外结算货币，只用于内容解锁。

不增加第四种货币。

### 13.2 商城功能

- 每次展示 4 件商品。
- M1 测试基线：普通波次整备完毕后恢复 35% 最大生命，避免首次构筑在下一波开始前失去验证机会。
- 购买武器、道具或即时补给。
- 刷新全部未锁定商品。
- 每件商品可独立锁定，最多同时锁定当前展示的 4 件商品至下一波。
- 同一次生成或刷新展示的商品必须互不重复；已锁定商品参与去重。
- 出售通用武器和宝物。
- 合成同名同级武器。
- 查看当前属性和流派标签。

### 13.3 价格基线

| 商品 | 价格区间 |
|---|---:|
| 普通 | 15–25 铜钱 |
| 稀有 | 35–55 铜钱 |
| 史诗 | 70–100 铜钱 |
| 传说 | 120–160 铜钱 |
| 恢复 25% 生命 | 18 铜钱 |
| 第一次刷新 | 4 铜钱 |

同一轮每次继续刷新，费用增加 2 铜钱；进入下一轮后重置。出售返还购买基准价的 60%。

### 13.4 经济目标

- 正常表现的玩家每波应获得约 40–70 铜钱。
- 每次进店应能购买一件普通商品，或为高稀有商品存钱。
- 玩家不应因为一次坏运气连续两轮完全买不起任何有效商品。
- 铜钱收益流派可以提高构筑速度，但必须通过敌人增量、价格或战斗属性付出代价。

## 14. 敌人与波次设计

### 14.1 敌人行为目录

| 敌人 | 行为 | 玩家应对 |
|---|---|---|
| 竹鼠 | 大量直线追击 | 范围攻击和移动 |
| 山猴 | 快速跳跃接近 | 保留闪避 |
| 甲壳野猪 | 高生命，正面减伤 | 绕后或持续输出 |
| 毒蜂 | 保持距离并射击 | 改变移动路线 |
| 鼬鼠刺客 | 预警后直线冲刺 | 横向闪避 |
| 狐妖术士 | 生成减速区域 | 离开危险地面 |
| 鼓手猕猴 | 强化附近敌人 | 优先击杀 |
| 竹林巢穴 | 固定生成小怪 | 突破敌群后摧毁 |
| 石甲龟 | 缓慢推进并阻挡路径 | 击退或绕行 |
| 妖雾灯灵 | 死亡后留下短时妖雾 | 控制击杀位置 |

### 14.2 精英规则

- 精英拥有更大轮廓、专属外圈和一个额外行为。
- 精英不只是普通敌人的血量放大版。
- 精英掉落保证包含铜钱，并有概率掉落治疗。
- 同屏精英数量必须受上限控制。
- M2 第一种精英为赤纹精英竹鼠：第 6 波起每波最多生成 1 只，拥有锁定方向的 0.9 秒蓄力冲刺，生命为同波普通竹鼠的 3 倍；击杀固定掉落 12 铜钱，并有 35% 概率掉落 10 点治疗。

### 14.3 波次生成

使用威胁预算而不是固定刷怪表：

- 每波拥有基础预算和随时间增长的预算速度。
- 不同敌人消耗不同预算。
- 远程、控制、召唤和精英敌人具有更高成本。
- 生成器限制同类高压敌人的同时出现数量。
- 敌人在玩家视野外生成，但不能直接堵死所有退路。
- MVP 测试基线：第 1 波普通敌人生命和伤害较低；之后每波提升生命，并分阶段提高接触、冲锋和投射物伤害，形成可观察的强度成长。
- M2 第一批开放节奏：第 1 波竹鼠；第 2 波山猴与毒蜂；第 3、4、5 波依次加入甲壳野猪、鼬鼠刺客、狐妖术士。初始威胁预算为 `2.5 + 波次 × 0.5`，每秒恢复 `0.7 + 波次 × 0.15`；首波理论生成量控制在约 45 只，后续通过种类、生命与伤害共同增压。
- M2 第一批同屏上限：山猴 4、甲壳野猪 4、鼬鼠刺客 3、狐妖术士 2；普通敌人总数不超过 80。

## 15. Boss 设计

### 15.1 共通规则

- MVP 只制作腐竹巨灵，并将其安排在第 10 波作为最终 Boss；獠牙先锋和赤羽妖鹤属于正式版扩展内容。
- 所有重击必须有清晰预警。
- Boss 必须提供短暂输出窗口。
- Boss 战允许存在少量普通敌人，但不能掩盖主要招式。
- Boss 不能频繁瞬移到玩家脚下。
- 半血阶段可以增加招式组合，不直接翻倍全部数值。

### 15.2 第 5 波：獠牙先锋

- 主题：巨型装甲野猪。
- 招式一：直线冲锋，撞到边界后眩晕。
- 招式二：三次践踏，生成递增圆形预警。
- 招式三：召唤少量竹鼠干扰。
- 检验：玩家是否理解预警、横向闪避和输出窗口。

### 15.3 第 10 波：赤羽妖鹤

- 主题：被妖气控制的赤鹤术士。
- 招式一：扇形羽毛弹幕。
- 招式二：生成缓慢移动的旋风区域。
- 招式三：飞离战场后沿预警线俯冲。
- 半血变化：弹幕与旋风组合出现。
- 检验：持续移动、弹道观察和远程输出能力。

### 15.4 正式版第 15 波 / MVP 第 10 波：腐竹巨灵

- 主题：由腐化竹根组成的巨型守卫。
- 招式一：竹根从地面连续刺出。
- 招式二：召唤巢穴并生成小怪。
- 招式三：拍击地面产生环形冲击波。
- 半血变化：部分地图区域被腐化，安全空间逐渐缩小。
- 濒死阶段：攻击节奏加快，但保留稳定输出窗口。
- 检验：最终构筑的清怪、单体、生存和移动能力。

MVP 数值验证基线：生命 2400；根刺预警 0.9 秒；环形冲击波预警 1.1 秒；每次召唤 3 只普通敌人；生命降至 50% 后腐化边界向内收缩 90 像素；进入第 10 波 90 秒仍未击败时进入狂暴并缩短招式间隔，不开启商城也不立即判负。

### 15.5 Boss 奖励

- 第 5、10 波：恢复部分生命，获得大量铜钱，并从三个史诗或传说宝物中选择一个。
- 正式版第 15 波或 MVP 第 10 波最终 Boss：进入通关结算。
- Boss 后下一次商城提高稀有和史诗商品权重。

## 16. 地图设计

### 16.1 MVP 地图：月影竹林

- 单个大尺寸矩形战斗区域。
- 中央开阔，边缘通过竹林、山石和薄雾封闭。
- 少量小型不可穿越石块用于改变路线，不形成迷宫。
- 地图大小允许玩家看到威胁方向，又不能靠直线逃跑永久脱战。
- 地图分为正常、轻度腐化和重度腐化三种环境阶段。

### 16.2 后续地图方向

- 云顶寺院：较多狭窄走廊和落雷区域。
- 翡翠梯田：多层视觉地形与水流减速区。
- 雪竹峰：周期性寒风推动角色和投射物。

后续地图不进入 MVP。

## 17. 局外成长与解锁

### 17.1 设计目标

- 鼓励尝试不同角色和流派。
- 失败后仍有小幅进度。
- 不让游玩时间直接替代操作和构筑能力。

### 17.2 解锁内容

- 新熊猫。
- 新武器和道具进入随机池。
- 新地图。
- 更高难度。
- 角色外观和竹林装饰。
- 图鉴条目与挑战徽章。

### 17.3 解锁示例

| 条件 | 奖励 |
|---|---|
| 使用山岚累计击杀 5,000 个敌人 | 解锁赤豆 |
| 单局护甲达到 30 | 解锁镇岳道具组 |
| 使用远程武器通关 | 解锁墨墨 |
| 单局触发 100 次气功效果 | 解锁白露 |
| 不购买治疗通关 | 解锁挑战徽章和外观 |

### 17.4 永久强化边界

MVP 不做永久属性树。正式版如果加入，永久战斗加成总量控制在约 5%–10%，并允许在挑战模式关闭。

## 18. UI/UX 方案

### 18.1 战斗 HUD

| 区域 | 内容 |
|---|---|
| 左上 | 生命、护盾、等级、经验条 |
| 顶部中央 | 波次、剩余时间、Boss 血条 |
| 右上 | 铜钱、击杀数、暂停入口 |
| 底部边缘 | 武器图标、等级和冷却状态 |
| 角色附近 | 短时状态、伤害数字和交互反馈 |

正常战斗时保持画面中央和下方移动区域清空。

### 18.2 升级界面

- 战斗完全暂停。
- 中央展示三张大卡片。
- 卡片包含名称、稀有度、效果、标签和变化预览。
- 有冲突或达到上限时明确提示。
- 支持键盘 1/2/3 和鼠标选择。

### 18.3 商城界面

- 左侧显示角色、属性和当前流派标签。
- 中央显示 4 件商品。
- 右侧显示武器与宝物栏。
- 底部提供刷新、锁定、出售和继续按钮。
- 购买后即时更新属性差异，不要求玩家自行计算。

### 18.4 主菜单

- 开始游戏。
- 熊猫选择。
- 图鉴与解锁。
- 设置。
- 制作信息。

### 18.5 可访问性

- 支持关闭屏幕震动。
- 支持降低非必要动画。
- 危险提示不只依赖颜色，配合形状和动画。
- 字号和 UI 缩放至少提供两档。
- 音乐、音效和提示音单独调节。

## 19. 音频方案

### 19.1 音乐

- 竹笛、木鱼、鼓点和轻电子节拍结合。
- 普通波次音乐保持清晰节奏，不持续堆满高频。
- Boss 音乐增强鼓点和低频，并在出场时切换段落。
- 商城音乐明显放松，让玩家感到安全。

### 19.2 音效层级

优先级从高到低：

1. 玩家受伤与危险预警。
2. Boss 招式和阶段变化。
3. 购买、升级和稀有掉落。
4. 玩家武器命中。
5. 普通敌人受击和死亡。
6. 环境音。

大量敌人同时受击时必须限制重复音效数量，避免爆音和听觉疲劳。

## 20. 技术架构

### 20.1 技术栈

- Phaser：2D 战场、精灵、动画、碰撞、摄像机和粒子。
- TypeScript：游戏逻辑与数据定义。
- Vite：开发和构建。
- DOM/CSS：HUD、升级、商城、暂停和结算界面。
- 本地 JSON 或 TypeScript 数据表：角色、武器、道具、敌人和波次配置。

### 20.2 系统边界

#### Simulation

负责：

- 玩家和敌人状态。
- 伤害、状态、计时器和触发器。
- 经验、升级、经济和掉落。
- 波次、Boss 和胜负。
- 可保存数据。

#### Renderer

负责：

- 场景、精灵、动画和摄像机。
- 粒子、受击反馈和预警表现。
- 输入采集与动作映射。

#### UI

负责：

- HUD。
- 升级、商城、暂停和结算。
- 展示数据，不作为战斗状态真相来源。

#### Content Data

负责：

- 熊猫、武器、道具、敌人、Boss 和波次配置。
- 稳定 ID，不使用文件名作为业务 ID。

### 20.3 关键规则

- 不把伤害、经验和波次规则散落在 Phaser 场景回调中。
- 不让 UI 直接修改渲染对象。
- 存档只保存可序列化数据，不保存 Phaser 对象。
- 随机系统使用可记录种子，便于复现平衡问题。
- 提供调试面板查看 FPS、实体数、波次预算、伤害统计和随机种子。

### 20.4 资源目录原则

资源按领域组织：

- `characters`
- `enemies`
- `weapons`
- `environment`
- `ui`
- `fx`
- `audio`

所有资源通过 manifest 稳定键访问。

## 21. 存档设计

### 21.1 保存内容

- 已解锁熊猫、武器、道具和地图。
- 挑战与成就进度。
- 设置项。
- 局外货币竹印。
- 统计数据。

### 21.2 不保存内容

MVP 不支持中途退出后恢复单局，不保存当前波次和临时构筑。浏览器异常关闭恢复可以后续评估。

### 21.3 存档要求

- 包含版本号。
- 支持旧版本迁移或安全回退。
- 无效字段使用默认值，不让单个字段破坏整个存档。

## 22. MVP 内容范围

### 22.1 必须包含

- 1 张地图：月影竹林。
- 3 只初始熊猫。
- 8 件武器。
- 24 件道具。
- 10 种普通敌人。
- 2 种精英变体。
- 1 个最终 Boss。
- 10 波、约 10–12 分钟。
- 自动攻击、移动和闪避。
- 升级三选一。
- 波次商城。
- 胜利、失败和统计结算。
- 基础音效和一套战斗音乐。
- 本地解锁存档。

### 22.2 明确不包含

- 多人联机。
- 移动端完整适配。
- 六名角色全部实装。
- 三张地图。
- 长剧情和过场动画。
- 永久属性树。
- 装备随机词缀。
- 每件武器都拥有进化。
- 在线账号和排行榜。

## 23. 开发里程碑

### M0：首轮视觉战斗原型

目标：证明移动、自动攻击、敌群和波次能够成立，并建立后续内容可复用的首轮视觉元素族规范。

验收：

- 玩家可以移动和闪避。
- 至少两种武器可以自动攻击。
- 至少三种敌人拥有不同行为。
- 5 分钟运行无明显实体泄漏和性能崩溃。
- 熊猫、三类敌人、双武器、战场地面和 HUD 采用统一视觉规范，不保留几何占位作为交付状态。

### M1：核心循环垂直切片

目标：跑通“战斗—升级—商城—下一波”。

验收：

- 3 只熊猫拥有不同被动。
- 升级三选一可用。
- 商城购买、刷新、锁定和出售可用。
- 一局可以正常胜利或失败。

### M2：内容与 Boss

目标：形成 10 波 MVP。

验收：

- 8 件武器、24 件道具和 10 种敌人数据接入。
- 最终 Boss 招式具有预警、输出窗口和阶段变化。
- 三类核心构筑可以完成通关。

### M3：美术、音频与体验

目标：从原型提升到可公开试玩版本。

验收：

- 三只熊猫动画一致且无尺寸漂移。
- HUD 不遮挡主要战场。
- 受击、暴击、购买、升级和 Boss 反馈清楚。
- 支持音量、震动和动画设置。

### M4：平衡与发布候选

目标：完成多轮试玩和稳定性修复。

验收：

- 不同角色和核心流派均有通关记录。
- 没有单一必选道具或完全无用的角色。
- 常见桌面分辨率可正常游玩。
- 中端设备高压波次维持目标帧率。

## 24. 数值与平衡原则

### 24.1 平衡目标

- 普通难度新玩家首次通关率目标：20%–35%。
- 第 5 分钟形成初步流派。
- 第 10 分钟构筑基本成型。
- 单个普通升级不应让总输出瞬间翻倍。
- 传说选择可以改变打法，但不保证自动通关。
- 防御构筑能活下来，但不能无限拖延。

### 24.2 构筑健康检查

至少验证以下流派：

- 山岚：近战范围 + 吸血。
- 山岚：高攻速 + 触发。
- 青团：投射物数量 + 穿透。
- 青团：暴击 + Boss 单体。
- 石墨：护盾 + 反击。
- 石墨：生命 + 范围震击。

### 24.3 禁止状态

- 角色站立不动即可永久无敌。
- 攻速或投射物无上限导致性能崩溃。
- 商城连续两轮不给任何有效购买。
- Boss 被无限击退、冻结或卡在边界。
- 某角色只有唯一可行构筑。

## 25. 测试与数据观察

### 25.1 每局记录

- 角色、随机种子和游戏时长。
- 到达波次和胜负。
- 每件武器的总伤害。
- 每件道具的购买次数。
- 升级选择和刷新次数。
- 受伤来源。
- 铜钱收入和消费。
- Boss 阶段死亡位置。

### 25.2 试玩问题

- 玩家能否在 30 秒内理解移动和攻击？
- 三只熊猫是否不用看文字就能感到打法不同？
- 玩家死亡时能否解释失败原因？
- 商城是否产生真实取舍？
- 是否存在三选一全部无效的情况？
- 战斗后期是否还能看清危险预警？
- 一局结束后玩家是否愿意换角色或构筑重开？

### 25.3 性能目标

- 目标帧率：桌面浏览器 60 FPS。
- 高压波次不能因伤害数字、粒子或掉落物无限累积导致持续下降。
- 使用对象池管理频繁生成的投射物、敌人和特效。
- 需要设置同屏敌人、投射物、掉落物和音效并发上限。

## 26. 主要风险与控制

| 风险 | 控制方式 |
|---|---|
| 一开始制作 6 只角色导致范围过大 | MVP 固定 3 只，其他角色只保留设计方向 |
| 随机升级出现大量废选项 | 标签加权、候选保护和上限过滤 |
| 后期特效遮挡 Boss 预警 | 危险层最高优先级，限制粒子和数字 |
| 商城与升级功能重复 | 升级负责属性/天赋，商城负责武器/道具/补给 |
| 防御构筑拖延战斗 | Boss 狂暴、敌潮预算增长和输出窗口要求 |
| 角色动画生成漂移 | 单一种子帧、整条生成、统一锚点和预览验收 |
| 游戏逻辑散落在渲染代码中 | Simulation、Renderer、UI 和 Content Data 分层 |
| 内容数量先于核心体验膨胀 | 每个里程碑按验收条件推进，不提前铺开正式版内容 |

## 27. 设计完成标准

一个功能只有同时满足以下条件才算完成：

1. 行为与本文档一致。
2. 数据可配置，没有把内容数值散落硬编码。
3. 有正常流程、失败流程和边界情况验证。
4. 画面反馈能解释状态变化。
5. 不遮挡关键战场信息。
6. 通过对应里程碑验收。
7. 如设计发生变化，本文档已同步更新。

## 28. Agent Loop 开发流程

所有可玩功能、游戏 UI、视觉反馈和运行时缺陷修复都必须执行 `docs/AGENT_LOOP.md` 定义的闭环：

```text
设计验收 → 最小实现 → 静态验证 → 运行游戏 → 浏览器试玩
→ 截图取证 → 预期对比 → UI_REQUIRED 判断 → 元素族规范
→ 资产生成与标准化 → 运行时替换 → 视觉复验 → 根因修复 → 回归验证
```

未获得真实运行与截图证据的视觉功能不能标记完成。玩家可见功能不能用未规范化占位图作为完成状态。循环只覆盖用户已经批准的功能范围，不自动授权新系统或下一里程碑。
